Pourquoi lazycam existe

Je voulais juste filmer mon écran pour des tutos. Étonnamment compliqué sous Linux.

🏗️
OBS Studio

Une usine à gaz pour ce simple besoin — et de plus en plus laissé à l'abandon.

🌊
Les autres outils

La plupart ne fonctionnent pas, ou mal, sous Wayland — pourtant le présent de Linux.

🪟
Bandicam

J'adorais sa simplicité, ce côté « j'appuie, ça filme ». Mais il n'existe que sous Windows.

Alors j'ai construit celui qui me manquait :
la simplicité de Bandicam, sur Linux, qui marche vraiment sous Wayland.

Pensé pour les tutos

Le bon geste, sans réglage à refaire à chaque fois.

⌨️

Une seule touche

Super+R démarre et arrête. Pas de fenêtre à viser, pas de clic.

🎙️

Micro automatique

Ordre de préférence : USB › webcam › interne. Le premier branché est pris, point.

🖥️

Écran automatique

Station d'accueil ou portable : lazycam filme le bon écran selon ce qui est branché.

⏯️

Pause / reprise

Super+Shift+R met en pause sans casser la synchro audio.

✂️

Montage auto

À l'arrêt, voix et vidéo sont recollées et normalisées dans un MP4 prêt à publier.

🎛️

Interface claire

Une fenêtre GTK pour ordonner micros/écrans, tester le niveau, régler la qualité.

Installation

Sur Ubuntu / Debian (GNOME). Ensuite, les mises à jour suivent avec apt upgrade comme le reste du système.

1

Ajouter le dépôt lazycam (une fois)

sudo install -m 0755 -d /etc/apt/keyrings curl -fsSL https://lazycam.coconweb.fr/apt/lazycam.gpg | sudo tee /etc/apt/keyrings/lazycam.gpg >/dev/null echo "deb [arch=amd64,arm64 signed-by=/etc/apt/keyrings/lazycam.gpg] https://lazycam.coconweb.fr/apt stable main" | sudo tee /etc/apt/sources.list.d/lazycam.list >/dev/null sudo apt update
2

Installer lazycam

sudo apt install lazycam
3

Moteur de capture + raccourci (une fois)

flatpak install -y flathub com.dec05eba.gpu_screen_recorder lazycam-shortcuts

Le raccourci s'active aussi via le bouton « Activer » dans lazycam-config. C'est tout — appuie sur Super+R.

Tu préfères sans dépôt ? Télécharge le .deb et sudo apt install ./lazycam_*.deb.
